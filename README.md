# Консольное приложение «Трекер прочитанных книг» (Модульная версия)

Это консольная программа на Python, которая помогает вести учет домашней библиотеки, ставить оценки книгам и смотреть детальную статистику по авторам.

---

 Архитектура проекта и структура модулей

* `main.py` — Интерфейс и управление. Отвечает за бесконечный цикл текстового меню, принимает ввод от пользователя и вызывает нужные функции из других модулей.
* `storage.py`*— Слой работы с данными (DAL). Отвечает за чтение и запись информации в файл `books.json`, удаление книг, а также проверяет логику на дубликаты.
* `stats.py` — Бизнес-логика и аналитика. Считает среднюю оценку по всей библиотеке и собирает статистику по каждому автору.
* `models.py` — Модели данных. Здесь живет класс `Book`, который описывает саму сущность книги и умеет превращать её в словарь для удобного сохранения в JSON.

---

В текстовом меню оператору доступны 6 базовых действий:
1. **Добавить книгу** — сохраняет автора, название, дату прочтения и оценку (от 1 до 5). Если книга с таким автором и названием уже есть, система выдаст предупреждение и не запишет дубликат.
2. **Показать все книги** — выводит весь список прочитанного в удобном формате.
3. **Показать среднюю оценку** — считает средний балл по всей библиотеке.
4. **Статистика по авторам** — показывает, сколько книг конкретного автора вы прочитали и какой у него средний балл.
5. **Удалить книгу** — удаляет запись из базы по её названию.
6. **Выход** — красиво закрывает программу.
